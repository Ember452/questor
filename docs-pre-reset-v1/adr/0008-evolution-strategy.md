# ADR-0008: 演进策略 — 接缝早锁、字段后锁；DAG/远程/分布式预留

- 状态：✅（2026-10-15）
- 背景：既要"第一天定得规范、方便超大规模扩展"，又防"过早焊死、后期大迁移"。
- 决策：
  - **接缝早锁**：run/seq、Command/Event 总线、权限决策模型、工具账本骨架、分层依赖方向。
  - **字段 v0 后锁**：任务树细节、断点粒度、recovery_pointers 形态——**跑通端到端 + 验证 2-3 个不同 Agent 策略后**再 lock（状态模型大改代价最高）。
  - **TaskTree v1 只用森林**（父子层级）；**DAG 跨节点依赖仅预留，v2 启用**（降 reduce/调度/恢复复杂度）。
  - **策略默认进程内**，经 `PolicyPort` 预留远程化；**不为远程/分布式提前序列化一切**。
  - **诚实天花板**：跨机**分布式 Harness**（状态排序/租约/exactly-once/部分失败恢复）是独立硬骨头，不是"扩事件"就到，需单独设计。
- 后果：v1 小而稳、演进不推翻分层；代价=部分能力(DAG/子agent编排/真沙箱/远程/分布式)明确后置。
- 备选(被否)：一次把 DAG/多agent/分布式全设计到位（过度工程、猜错变化轴）→ 否。
