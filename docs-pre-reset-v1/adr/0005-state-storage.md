# ADR-0005: 状态存储 — 事件溯源为主 + turn 边界轻量快照为辅

- 状态：✅（2026-10-15）
- 背景：既要可回放/续传/审计，又不能因重放超长事件日志而读放大、或频繁全量快照撑爆存储。
- 决策：
  - **事件表 append-only** + `seq` 索引为主；
  - **turn 边界生成轻量快照**（`Domain_State` 投影，可只存 seq 游标/引用而非全量消息拷贝）；
  - **恢复 = 取最近快照 + 重放其后事件**；两种机制**都要有**，不偏废其一。
  - `transient` 的 `text_delta` 等**绝不持久化**（`Message`=完整最终块才落库）。
- 后果：续传/回放/审计免费、断点自然；代价=事件日志增长，需配压缩/归档策略；schema 演进要带版本+迁移。
- 备选(被否)：纯事件溯源（长会话读放大）→否；纯全量快照（IO/存储膨胀、丢历史）→否。
