## 3. 路① findings（契约完备性/不变式破坏）— 全部闭

- **M1（Major·闭）**：`tools_changed` 若当 durable → 能力增删在 loop 外、活 run 面已冻结，会陷"host 直 `bus.emit` 违 reduce-purity / 无 run 可挂"。收口：定为 **live-only**（入 `LIVE_ONLY`、不占 durable seq、不入库，`events.py:31-33`），由 loop 自身在 generation bump 安全点发（`loop.py::_maybe_announce_capability`），host 只 bump `generation` 不碰 bus。落 ADR-0046 + `test_capability_generation`。
- **M2（Moderate·闭）**：`--resume` 须用创建时冻结的 `policy_ref`、绝不重解析 registry（否则撕裂）。`rebuild_run` 从快照 `from_snapshot` 恢复 `policy_ref`（`snapshot.py` additive、旧快照读 None）；`run_started` 仅 `was_idle` 时发一次，resume 不重发。落 ADR-0045 / `test_p9_policy_hotswap`。
- **I1（Info·闭）**：`Run.policy_ref` additive 不破快照 round-trip：`test_policy_ref_contract.py::test_old_snapshot_without_policy_ref_reads_none`；`store_schema_version` 未破坏性升版（additive 列走 `IF NOT EXISTS`）。

## 4. 路② findings（范围/安全/第二写者/载荷/热插稳定性）— 全部闭

- **S1（安全·Major·闭）**：OpenAI wire 无审批通道 → 若降 allow 即"外部进程无 HITL 驱动高危工具"。鉴权 lane 起 run 采保守默认（`permission_mode=default`、`ask` 超时 fail-closed deny、lane 工具 capability floor 收窄），写/执不因"外部可调"放行（承 C17/ADR-0043⑦）。
- **S2（第二写者/多进程·闭）**：鉴权外部 lane 若作独立进程与桌面 sidecar 共享 SQLite → 同 run_id 双驱风险由 `run_lease`（epoch + `BEGIN IMMEDIATE`）拦（`test_run_lease_multiprocess` 实测恰一赢家）；OpenAI 入站仅经 inbox（C16）。
- **S3（载荷外泄·闭）**：API-key 不入库/进事件/进日志（surface 比对即弃，承 C20/ADR-0019）；OpenAI 投影只带界 preview/artifact_ref（`tool_completed` data 白名单），正文不内联。
- **R1（范围·闭）**：不移植 cordis TS 容器（薄宿主复用现成注册点）；发现=组合根固定名册、无磁盘 HMR；跨机 claim/lease 天花板不做（§2）。
- **带外双投（pitfalls#5·闭）**：`test_p9_openai_out_of_band_projection.py`——CLI+SSE+OpenAI **三**消费者同 run，主干日志每 seq 恰一行（回到逐消费者投影即翻倍→判红）。
