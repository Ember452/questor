# ADR-0050: 卫生面回收边界（lease/TTL 账本回收 + artifact 孤儿 GC；event_log 主干裁剪与 acked-delivery 回收绑定后置）

- 状态：✅（2026-10-19，P10 开工前置门；实现见 [`../plan/10-p10-hardening.md`](../plan/10-p10-hardening.md) Lane D，T0 先此 ADR）
- 背景：三处显式后置 P10 的卫生账本——[`ADR-0019`](./0019-bounded-artifact-projection.md):12 "需要独立 artifact GC/session cleanup，后续可归 P10"；[`ADR-0022`](./0022-dual-cursor-watermark.md):12 "watermark 永不回收（防 ABA），裁剪策略后置 P10"；[`ADR-0047`](./0047-cross-process-claim-delivery-run-lease.md) P9 加了 `claim_delivery/delivery_state/acquire_lease/renew_lease/release_lease`（contracts/ports.py:96-123）但**只增不回收**、账本无界增长。现场核（`cfc3004`）：`contracts/ports.py` 无 `prune/gc/reclaim/delete` 方法；`providers/artifact_store.py::FileSystemArtifactStore` 仅 `put_text/put_bytes`、**无 read/GC**，且**内容寻址、落盘路径 = `root/{sha256}{suffix}`、run_id 未进路径**（docstring 称"按 run 隔离"与实现不符，登记）。[`ADR-0024`](./0024-memory-contract-evolution.md)/[`ADR-0048`](./0048-recoverable-context-compaction.md) 令压缩 `recovery_pointers` 指向 **durable `event_log`** 区间——故 event_log 不可裁，否则压缩恢复与回放权威（[`ADR-0020`](./0020-durable-write-gate-and-log-authority.md)）崩塌。
- 决策：
  1. **`event_log` 主干裁剪显式后置、不在本 Phase**：`event_log` 是 [`ADR-0020`](./0020-durable-write-gate-and-log-authority.md) 唯一耐久权威、[`ADR-0048`](./0048-recoverable-context-compaction.md) 的 `recovery_pointers(seq_from,seq_to)` 与 `--resume`/`replay_global` 全依赖其完整 append-only；裁剪三者同时失效。**登记理由**（防"字段存在≠已做"）。
  2. **claim/delivery/lease 回收 = 限"过期/已释放 `run_lease` 行 + 超 TTL 未 ack 的 in-flight claim"**：这些是**派生瞬态视图**、可安全重取（ADR-0047"投递视图从事件重建、非第二真相"）。**绝不裁已 acked 的 `delivery_state` 行（对抗评审 BLK-2）**：delivery_id 是幂等键、视图从**不裁**的 `event_log` 重建，裁掉 acked 行会让 rebuild 重新 claim→双投、恰破 exactly-once；acked-delivery 行的回收**与 event_log 裁剪绑定后置**。新增 `StorePort` 纯增量方法（`reclaim_leases(now)`/`reclaim_expired_claims(now)`），schema 单一 authority、未知版本 fail-closed（承 ADR-0022/0047）。
  3. **artifact GC = 仅孤儿扫描**：删"不被**任何**保留 event/checkpoint 引用"的 artifact（写失败、或崩于"写 artifact 与发 `tool_completed` 之间"的孤儿）；内容寻址去重 → 删前全量可达性扫描、确认无其它 run 引用同 digest。**"terminal-run session cleanup" 不在本 Phase**（对抗评审 MAJ-7）：因 D1 不裁 event_log，终态 run 的 `tool_completed.artifact_ref` 恒在库 → 其 artifact 永不可安全删；真 session 级 artifact 回收**与 event_log 裁剪绑定后置**，不虚称。
  4. **文档-实现偏差就地登记不回改**：artifact store "按 run 隔离" docstring 与"内容寻址、run_id 不入路径"实现不符 → 以实现为准，GC 按可达性非按目录；此偏差回填 CHANGELOG、历史 docstring 不回改（AGENTS §5.5 reality-wins）。
- 后果：正面——增长最快的瞬态 lease/claim 有确定回收；孤儿 artifact 可清；压缩恢复链（recovery_pointers↔event_log）与 exactly-once（acked delivery）两条不变式都被机器守而不被"回收"误伤。代价——P10 的"卫生"是**保守子集**（lease/TTL + 孤儿 artifact），event_log/acked-delivery/session-artifact 三项真回收统一绑 event_log 裁剪后置，须清晰注释防误读为"已全做"。
- 备选（被否）：
  1. 本 Phase 裁 event_log 腾盘：破压缩恢复 + 回放权威 + `--resume`（ADR-0020/0048）→ 否。
  2. 按 horizon 裁 acked delivery 行：rebuild 重 claim→双投破 exactly-once（BLK-2）→ 否。
  3. 按 run 目录删 artifact 做 session cleanup：内容寻址跨 run 去重会错删活跃引用；且 event_log 不裁时终态 run artifact 本就可被引用（MAJ-7）→ 否。
