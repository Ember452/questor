# ADR-0048: 可恢复上下文压缩转正（CompactContext Command + compact_* additive 事件 + CompactionConfig）

- 状态：✅（2026-10-19，P10 开工前置门；实现见 [`../plan/10-p10-hardening.md`](../plan/10-p10-hardening.md) Lane A，T0 先此 ADR）
- 背景：压缩此前被四道接缝"定形但无生产者"悬置——[`ADR-0024`](./0024-memory-contract-evolution.md):10 定 `recovery_pointers` 为 typed `(seq_from,seq_to,covered_hash)` 但**写锚生产者随 `disable_compaction=True` 后置 P10**；[`ADR-0025`](./0025-memory-distill-atomicity.md):12 把"压缩→L2' 蒸馏桥"只留接缝；[`../design/01-state-model.md`](../design/01-state-model.md) §2 `Context.compaction_floor/summary/recovery_pointers` 三字段、§5 `pre_compact` 检查点 kind、§12 **I2**"压缩属 Kernel 行为、策略只能发 advisory"；[`../design/02-event-protocol.md`](../design/02-event-protocol.md) §2/§10 `compact_started/applied` + `baseline_seq` 栅栏均纸面。现场核（`cfc3004`）：`contracts/events.py::EventType` 22 类**无 `compact_*`**、`state/reduce.py` **无任何压缩分支**、`kernel/loop.py::_checkpoint` 仅被 `final/auto/post_tool/pre_tool` 调用（**`pre_compact` 从未发射**）、`contracts/policy.py:89 LoopPolicy.disable_compaction=True`、`state/checkpoint.py:12 closed_prefix` 是配对安全截断的唯一判据。peer-scan：hermes `agent/context_compressor.py:1-2`（保头尾、中间摘要、工具输出先剪）+ `conversation_compression_reply_anchor.py`（回复/用户轮锚）、wuu `internal/agent/compaction_note.go:20-21,74-75`（`CoveredHash` + 剔除 thread-local seq/tool-ledger 地址）、DeepCode `core/agent_runtime/compaction.py`、wuu `adaptive_compact.go:99`（阈值单源）。
- 决策：
  1. **触发归内核（I2）**：`kernel/loop.py` 在 turn 边界安全点（`_checkpoint("auto")` 之后、下一次 provider 调用之前）据 token/窗口估算决定是否压缩；`AdviseCompact`（policy.py:56）/`RequestCompactHint`（events.py:146）**仅 advisory**、内核不被强制、`reduce` 现不处理 hint 的语义不破。阈值取单一真源（`Budget`/context-window 估算），loop 只消费不重算（wuu 口径）。
  2. **压缩必经 Command→reduce→durable（C2/C16，禁 out-of-band）**：新增内核内部 Command `CompactContext(run_id, covered_from, covered_to, covered_hash, summary_text, new_floor, recovery_pointers?, distill?)`；`reduce` 对它**只做纯校验 + 纯应用**。
  3. **reduce 纯函数铁律（对抗评审 MAJ-8）**：摘要文本、`covered_hash`、新 `floor`、`recovery_pointers` 一律由 **loop 侧（可插拔摘要策略，非 provider-in-reduce）算好后随命令负载携带**；reduce **绝不计算摘要/哈希**——否则 `pre_compact` 快照尾重放含 `CompactContext` 时重跑摘要器破回放确定性。判据：同一 `CompactContext` 命令两次 reduce 结果逐字相等。
  4. **截断边界只认 `closed_prefix`（C19/ADR-0028）**：压缩只在"每个 `tool_use` 已配 `tool_result`"的最长前缀内截断（`state/checkpoint.py`），尾窗未闭合调用原样保留——压缩**绝不孤儿化 open tool_use**；回发前关卡（`_stream_turn::ensure_paired_history`）照旧。
  5. **可恢复锚 fail-closed（ADR-0024 生产者转正）**：**截断前**写 `RecoveryPointer(seq_from, seq_to, covered_hash)`；`seq_from/seq_to` = 被逐消息区间在 **durable `event_log`** 的 seq 边界，原文从 append-only `event_log` 回读（与本 Phase"不裁 event_log"决策强耦合）；`covered_hash` = 对该 seq 区间消息内容规范化哈希、**剔除 per-run seq 与 `tool_call_id` 等易变字段**（wuu compaction_note.go:74-75）；读回前 `matches()` 校验、历史漂移 fail-closed 拒返旧内容。**迭代压缩**：新摘要 = fold(前摘要 + 新逐出区)，`recovery_pointers` 只追加、绝不改写旧锚。
  6. **`pre_compact` 检查点 + `compact_*` additive 事件**：压缩前落 `pre_compact` 全量快照（可确定性还原压缩前态）；`compact_started`/`compact_applied` 作为内部事件投影出**外部精简集**——`compact_applied.data` 仅 `{baseline_seq, covered_from, covered_to, summary_bytes}`、**无正文**（C18/C20）；`baseline_seq` 为**重写栅栏提示**供渲染侧重折上下文视图，因 log 完整、`after_seq` 回放仍有效，**不强制 resync**（仅游标越界/版本不符走既有 `resync_required`）。四处 lockstep（`EventType`+`EXTERNAL_EVENT_FIELDS` ⟂ `protocol/event.schema.json` ⟂ TS codegen ⟂ `check_protocol_schema`），**`v` 不 bump**。
  7. **L2' 蒸馏桥转正（ADR-0025）**：压缩丢弃区可选发 `WriteMemory(MemoryWrite{kind=distill, covered_from/to/hash, text=浓缩文本})` → daily，经同一 `MemoryStorePort` 收口（C4）；正文只放浓缩、绝不放 delta/原文（I3）。
  8. **开关转正**：`LoopPolicy.disable_compaction: bool` → `LoopPolicy.compaction: CompactionConfig | None`（additive、`None`/未启用向后兼容既有快照）。摘要生产者默认**确定性启发式**（复用 `__main__._HeuristicDistiller` 形状、无 LLM、eval 可复现）；provider 摘要为可选门、其产物同样写入 `Domain_State.summary` 随快照持久（回放不重算）。
  9. **回放确定性扩面**：`scripts/check_replay_determinism.py` 增含 `CompactContext`/`compact_applied`/`baseline_seq` 的 fixture，断言 (连续 reduce) == (最近快照 + 尾重放)，`--self-test` 对"截断尾/破坏配对/篡改覆盖区/去写锚"必判红、fail-on-empty 保持。
- 后果：正面——ROADMAP §1 P10 DoD"压缩不丢事实召回"可机器验证（covered_hash fail-closed + 回放确定性 + C19 配对）；快照 schema 保持 v3 不 bump（ADR-0024 已前置定形，兑现"不必破坏性返工"）。代价——压缩是 turn 循环新增状态转移，须持续守 reduce 纯函数与 `closed_prefix` 边界；真 LLM 摘要质量标 UNVERIFIED（eval 用确定性启发式，不用真 key）。
- 备选（被否）：
  1. out-of-band 直改 `context.items`（loop 里就地截断）：违 C2 单写者、撕裂回放/断点 → 否。
  2. 让策略发"强制压缩"命令：违 design/01 I2"压缩属 Kernel" → 否（advise 仅 advisory）。
  3. 截断先于写锚 / 不写 covered_hash：丢原文不可恢复且读回无 fail-closed 依据 → 否（ADR-0024）。
  4. reduce 内计算摘要/哈希：reduce 不纯、`pre_compact` 尾重放破确定性 → 否（MAJ-8）。
  5. 现在就裁 event_log 腾空间：与 `recovery_pointers` 指向的 append-only 区间、与单真相 [`ADR-0020`](./0020-durable-write-gate-and-log-authority.md) 直接冲突 → 否，主干裁剪 [`ADR-0050`](./0050-p10-hygiene-reclamation.md) 点名后置。
